# Banking System — Java OOP Practice

A simple Banking System built in Java to revise and practically demonstrate core Object-Oriented Programming concepts.

This project was created as a hands-on OOP revision exercise before moving into advanced Java and Spring Boot concepts.

## 🎯 Purpose

The goal of this project is to understand OOP concepts by implementing them in a small, connected banking domain instead of studying them only theoretically.

The project demonstrates:

- Classes and Objects
- Encapsulation
- Constructors
- `this` and `super`
- Access Modifiers
- Inheritance
- Abstract Classes
- Abstract Methods
- Method Overriding
- Runtime Polymorphism
- Interfaces
- Association
- Aggregation
- Composition
- Enums
- `toString()`
- `equals()`
- `hashCode()`
- `HashSet`
- Exception Handling
- Custom Exceptions
- `throw` and `throws`
- Checked vs Unchecked Exceptions
- Collections and Generics
